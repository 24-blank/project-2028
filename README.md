# 2048 Game in Python (Pygame)

A simple implementation of the classic 2048 game built using Python and Pygame.

## Features

- Smooth tile movement animations
- Tile merging logic
- Random tile spawning
- Keyboard controls
- Clean UI inspired by the original 2048 game

---

## Tech Stack

- Python 3
- Pygame

---

## Installation

### 1. Clone the repository

```bash
git clone git@github.com:24-blank/project-2048.git
cd project-2048
```

### 2. Install dependencies

```bash
pip install pygame
```

### 3. Run the game

```bash
python main.py
```

---

## Controls

| Key | Action |
|-----|--------|
| ↑ | Move Up |
| ↓ | Move Down |
| ← | Move Left |
| → | Move Right |
